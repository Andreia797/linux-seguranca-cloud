# Acesso remoto por SSH

## O que é SSH?
Protocolo para acesso remoto seguro a servidores Linux.

## Que informação seria necessária para aceder a um servidor por SSH?
- Utilizador: username
- Endereço IP: IP do servidor
- Porta: 22
- Palavra-passe ou chave: credenciais de acesso

## Exemplo de comando de ligação
ssh utilizador@endereco_ip
