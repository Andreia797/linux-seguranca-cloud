# Monitorização

## Tempo de atividade

Comando utilizado:

```bash
uptime
```

## Memória

Comando utilizado:

```bash
free -h
```

## Espaço em disco

Comando utilizado:

```bash
df -h
```

## Serviço web

Comando utilizado:

```bash
systemctl status nginx
```

## Observações

O serviço Nginx encontrava-se ativo e o sistema apresentava recursos disponíveis para funcionamento normal.
