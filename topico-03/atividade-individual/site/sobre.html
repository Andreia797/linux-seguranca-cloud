Sobre o Projeto

O Space Explorer é uma plataforma educativa criada para divulgar conhecimentos sobre astronomia e exploração espacial.

O projeto apresenta informações sobre planetas, missões históricas e tecnologias que poderão transformar o futuro das viagens espaciais.

Este website foi desenvolvido utilizando apenas HTML e CSS, explorando conceitos modernos de design responsivo, animações e interfaces futuristas.

O objetivo é proporcionar uma experiência visual envolvente, inspirada em interfaces tecnológicas e ficção científica.
